# 发布文案草稿

今天第二个开源小工具：ReqNote · 请求便笺。

把浏览器复制出来的cURL粘进来，整理成请求说明，切换Fetch、Axios、Python、HTTP或cURL代码。分享前按规则替换token、Cookie和敏感字段；遇到业务字段可以自己补规则。

React + Vite + TypeScript，纯本地转换，不执行命令、不发送请求、不存请求历史。MIT开源，附Node API和CLI。

在线：https://batype.github.io/reqnote/
源码：https://github.com/batype/reqnote

15秒演示：默认JSON请求 → 查看已替换3处 → 添加email得到4处 → 切Python → 复制代码 → 切暗色模式。

这是草稿，没有自动发布到社交平台。
